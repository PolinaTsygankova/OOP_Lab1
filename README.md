🏡 Smart House Management SystemКонсольний C# застосунок для управління об'єктами «Smart House», створений у межах лабораторної роботи з ООП.   
📌 ФункціоналДодавання та перегляд: створення будинків із валідацією даних та виведення їх у вигляді таблиці.   Пошук: фільтрація об'єктів за 2 характеристиками.   Поведінка: зміна режимів (HouseMode), налаштування температури, охорони та перевірка напруги.   Видалення: вилучення записів за номером або власником.   
🛠 СтекC# (.NET), Console Application, ООП.
