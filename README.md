# 🏡 Smart House Management System

Консольний C# застосунок для інтелектуального управління та моніторингу об'єктів «Smart House», розроблений у межах лабораторної роботи з об'єктно-орієнтованого програмування.

---

## ⚡ Основні можливості

* **Управління об'єктами:** додавання розумних будинків із суворою валідацією типів, діапазонів та формату даних.
* **Табличний перегляд:** форматоване відображення списку всіх зареєстрованих будинків у консолі.
* **Пошук та фільтрація:** швидкий пошук об'єктів за комбінацією 2 характеристик.
* **Симуляція поведінки:** перемикання режимів (`Home`, `Away`, `Econom`, `Night`, `Vacation`), автоматична активація охорони та контроль напруги.
* **Видалення записів:** вилучення об'єктів із системи за номером або ім'ям власника.

---

## 🛠 Технологічний стек

* **Мова програмування:** C# (.NET)
* **Архітектура:** ООП (інкапсуляція, класи, enum)
* **Тип додатка:** Console Application
